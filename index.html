Engineering Mathematics-I

8 detailed topics • Definition • Key points • Formula • Examples • Quick tip

📌 Definition

Derivative kisi function ke change ki instantaneous rate ko batata hai.

📚 Key Formula / Points
Power rule: d(xⁿ)/dx = n xⁿ⁻¹. Product rule: (uv)' = u'v + uv'. Chain rule: d[f(g(x))]/dx = f'(g(x))g'(x).
🧩 Examples
Example: y=x³+2x ⇒ dy/dx=3x²+2. Example: y=sin x² ⇒ dy/dx=2x cos(x²).
💡 Exam Tip

Derivative ka use slope, velocity, maxima-minima aur approximation mein hota hai.

📌 Definition

Jab function mein ek se zyada independent variables hon aur ek variable ke respect mein derivative liya jaye, use partial differentiation kehte hain.

📚 Key Formula / Points
∂/∂x means y,z ko constant maan kar x ke respect mein differentiate karna.
🧩 Examples
Example: z=x²y+3y² ⇒ ∂z/∂x=2xy; ∂z/∂y=x²+6y.
💡 Exam Tip

Jis variable ke respect mein derivative hai, baaki variables constants hote hain.

📌 Definition

Function ka local maximum highest nearby value aur local minimum lowest nearby value hota hai.

📚 Key Formula / Points
Critical point ke liye f'(x)=0. Second derivative test: f''(x)<0 ⇒ maximum f''(x)>0 ⇒ minimum.
🧩 Examples
Example: f=x²-4x+3. f'=2x-4=0 ⇒ x=2. f''=2>0, so minimum.
💡 Exam Tip

Engineering optimization problems mein iska use hota hai.

📌 Definition

Kisi function ko powers of x ke sum ke form mein approximate karne ki technique series expansion hai.

📚 Key Formula / Points
Taylor: f(x)=f(a)+(x-a)f'(a)+(x-a)²f''(a)/2!+... Maclaurin mein a=0.
🧩 Examples
eˣ=1+x+x²/2!+x³/3!+... sin x=x-x³/3!+x⁵/5!-...
💡 Exam Tip

Approximation aur numerical calculations mein useful.

📌 Definition

Rows aur columns mein arranged numbers ka rectangular array matrix kehlata hai.

📚 Key Formula / Points
Determinant 2×2: |a b; c d| = ad-bc. Inverse: A⁻¹=adj(A)/|A|, when |A|≠0.
🧩 Examples
Example: A=[[2,1],[3,4]] |A|=8-3=5.
💡 Exam Tip

Matrices simultaneous equations, transformations aur engineering computation mein useful hain.

📌 Definition

Matrix ki maximum number of linearly independent rows/columns ko rank kehte hain.

📚 Key Formula / Points
Elementary row operations se echelon form bana kar non-zero rows count ki ja sakti hain.
🧩 Examples
Example: [[1,2],[2,4]] ka rank 1 hai kyunki second row first ka 2 times hai.
💡 Exam Tip

Linear equations ki consistency check karne mein important.

📌 Definition

Unknown function aur uske derivatives wali equation differential equation hoti hai.

📚 Key Formula / Points
Order highest derivative ka order hota hai. First-order equations mein variable separation, homogeneous aur linear methods common hain.
🧩 Examples
Example: dy/dx=2x ⇒ y=x²+C.
💡 Exam Tip

Physics, circuits, growth/decay aur dynamic systems model karne mein use hota hai.

📌 Definition

Do ya zyada variables par integration ko multiple integration kehte hain.

📚 Key Formula / Points
Double integral: ∬ f(x,y)dA. Area/volume aur mass distribution jaise problems mein use hota hai.
🧩 Examples
Example: ∬_R 1 dA region R ka area deta hai.
💡 Exam Tip

Limits ko region ke according carefully set karna sabse important step hai.

Engineering Physics

8 detailed topics • Definition • Key points • Formula • Examples

📌 Definition

Microscopic particles jaise electrons aur photons ke behaviour ka theory quantum mechanics hai.

📚 Key Formula / Points
Energy quantization, wave-particle duality, uncertainty principle aur wave function important ideas hain.
🧩 Examples
Photon energy E=hν. Frequency double ho to photon energy bhi double hoti hai.
💡 Exam Tip

Nanoelectronics, lasers aur semiconductor devices mein foundation.

📌 Definition

Light aur matter dono wave aur particle jaise properties show kar sakte hain.

📚 Key Formula / Points
Photon: E=hν p=h/λ Matter wave: λ=h/p
🧩 Examples
Electron ka momentum badhe to de Broglie wavelength kam hoti hai.
💡 Exam Tip

Modern physics ka fundamental concept.

📌 Definition

Position aur momentum ko ek saath arbitrarily high precision se measure nahi kiya ja sakta.

📚 Key Formula / Points
Δx Δp ≥ ħ/2.
🧩 Examples
Microscopic particle ko bahut small region mein confine karne par momentum uncertainty badh sakti hai.
💡 Exam Tip

Atomic-scale systems mein important.

📌 Definition

LASER ka full form Light Amplification by Stimulated Emission of Radiation hai.

📚 Key Formula / Points
Laser light highly coherent, directional aur generally monochromatic hoti hai. Population inversion aur stimulated emission key concepts hain.
🧩 Examples
Laser pointer mein narrow, directional beam milti hai.
💡 Exam Tip

Uses: communication, surgery, barcode scanners, industry.

📌 Definition

Optical fibre glass/plastic medium hai jisme light ke through information transmit hoti hai.

📚 Key Formula / Points
Principle: Total Internal Reflection. Core ka refractive index cladding se higher hota hai.
🧩 Examples
Internet fibre mein data light pulses ke form mein travel karta hai.
💡 Exam Tip

High bandwidth aur low signal loss ke karan communication mein useful.

📌 Definition

Optical fibre ki light-gathering ability ko numerical aperture describe karta hai.

📚 Key Formula / Points
For air outside: NA = √(n₁²-n₂²)
🧩 Examples
Example: n₁=1.50, n₂=1.47 ⇒ NA≈0.301.
💡 Exam Tip

Higher NA generally easier light coupling deta hai.

📌 Definition

Semiconductor ki electrical conductivity conductor aur insulator ke beech hoti hai.

📚 Key Formula / Points
Intrinsic semiconductor pure hota hai. Extrinsic mein doping se n-type/p-type banta hai.
🧩 Examples
Silicon mein phosphorus doping se n-type semiconductor milta hai.
💡 Exam Tip

Diodes, transistors aur ICs ka base.

📌 Definition

Changing electric aur magnetic fields se propagate hone wali waves electromagnetic waves hoti hain.

📚 Key Formula / Points
Vacuum mein c≈3×10⁸ m/s aur c=fλ.
🧩 Examples
Radio waves, microwaves, visible light, X-rays sab EM spectrum ka part hain.
💡 Exam Tip

Communication, imaging aur sensing mein applications.

Engineering Chemistry

8 detailed topics • Definition • Key points • Formula • Examples

📌 Definition

Atom element ki basic chemical unit hai, jisme nucleus aur electrons hote hain.

📚 Key Formula / Points
Nucleus mein protons/neutrons; electrons quantized energy levels mein milte hain. Atomic number = protons.
🧩 Examples
Carbon ka atomic number 6 hai, neutral atom mein 6 electrons hote hain.
💡 Exam Tip

Electronic configuration chemical behaviour ko strongly influence karti hai.

📌 Definition

Electron ki state ko describe karne wale four quantum numbers n, l, mₗ, mₛ hain.

📚 Key Formula / Points
n=shell l=subshell mₗ=orbital orientation mₛ=spin
🧩 Examples
n=2 mein l=0 or 1 possible hai.
💡 Exam Tip

Electronic configuration aur periodic properties samajhne mein useful.

📌 Definition

Atoms stable electronic arrangement ke liye chemical bonds banate hain.

📚 Key Formula / Points
Ionic bond electron transfer se, covalent bond sharing se aur coordinate bond shared pair donation se banta hai.
🧩 Examples
NaCl mein Na⁺ aur Cl⁻ ke beech ionic bonding hoti hai; H₂ mein covalent bond.
💡 Exam Tip

Molecular structure aur properties bonding par depend karti hain.

📌 Definition

Water mein Ca²⁺ aur Mg²⁺ salts ki presence se hardness hoti hai.

📚 Key Formula / Points
Temporary hardness bicarbonates se aur permanent hardness sulphates/chlorides se related hoti hai.
🧩 Examples
Soap ke saath hard water mein scum banta hai.
💡 Exam Tip

Boiler problems aur water treatment ke liye important.

📌 Definition

Hardness-causing ions ko remove/reduce karne ki process water softening hai.

📚 Key Formula / Points
Methods: lime-soda, zeolite aur ion-exchange.
🧩 Examples
Ion-exchange plant hard water ko low-hardness water mein convert karta hai.
💡 Exam Tip

Industrial boilers mein scale prevention ke liye important.

📌 Definition

Metal ka environment ke saath chemical/electrochemical reaction ke karan gradual deterioration corrosion hai.

📚 Key Formula / Points
Types: dry chemical corrosion wet electrochemical corrosion. Prevention: painting, coating, alloying, cathodic protection.
🧩 Examples
Iron rusting oxygen aur moisture ki presence mein hoti hai.
💡 Exam Tip

Bridges, pipelines aur machines ki life improve karne ke liye control zaroori.

📌 Definition

Bahut saare repeating monomer units se bana high molecular mass molecule polymer hai.

📚 Key Formula / Points
Addition polymerization mein unsaturated monomers add hote hain. Condensation polymerization mein small molecule release ho sakta hai.
🧩 Examples
Ethene → polyethylene. Nylon is a common engineering polymer.
💡 Exam Tip

Packaging, fibres, insulation aur components mein use.

📌 Definition

Chemical products/processes ko aise design karna ki hazardous substances aur waste minimum ho, green chemistry hai.

📚 Key Formula / Points
Waste prevention, safer solvents, energy efficiency aur renewable feedstocks key ideas hain.
🧩 Examples
Solvent-free or water-based processes hazardous organic solvents ko reduce kar sakte hain.
💡 Exam Tip

Sustainable engineering aur pollution reduction ke liye important.

Basic Electrical Engineering

8 detailed topics • Definition • Key points • Formula • Examples

📌 Definition

Constant physical conditions par current voltage ke directly proportional hota hai.

📚 Key Formula / Points
V=IR I=V/R R=V/I
🧩 Examples
V=12V aur R=6Ω ⇒ I=2A.
💡 Exam Tip

Basic circuit calculations ka starting point.

📌 Definition

Kisi junction par entering currents ka algebraic sum leaving currents ke equal hota hai.

📚 Key Formula / Points
ΣI=0 at a node.
🧩 Examples
2A aur 3A enter karte hain, to total 5A leave karega.
💡 Exam Tip

Complex networks ke node analysis mein use.

📌 Definition

Closed loop mein all voltage rises aur drops ka algebraic sum zero hota hai.

📚 Key Formula / Points
ΣV=0.
🧩 Examples
10V source aur 4Ω+6Ω series resistance ⇒ I=10/10=1A.
💡 Exam Tip

Loop analysis aur circuit solving mein useful.

📌 Definition

DC current ka direction ideally constant hota hai; AC current time ke saath magnitude/direction change karta hai.

📚 Key Formula / Points
Sinusoidal AC: v=Vₘ sinωt. RMS: V_rms=Vₘ/√2.
🧩 Examples
Household supply is AC; battery output is DC.
💡 Exam Tip

Transmission aur electronics mein dono ka role hai.

📌 Definition

Electrical power energy transfer ki rate hai.

📚 Key Formula / Points
P=VI=I²R=V²/R. Electrical energy E=Pt.
🧩 Examples
100W bulb 5h chale ⇒ 500Wh = 0.5kWh.
💡 Exam Tip

Electricity consumption aur billing samajhne mein useful.

📌 Definition

AC circuit mein real power aur apparent power ka ratio power factor hota hai.

📚 Key Formula / Points
pf=cosφ=P/S. Pure resistive load ka pf≈1.
🧩 Examples
Low power factor se same useful power ke liye higher current flow ho sakta hai.
💡 Exam Tip

Industrial systems mein power factor correction important.

📌 Definition

Transformer mutual induction se AC voltage/current level change karta hai.

📚 Key Formula / Points
Ideal transformer: V₂/V₁=N₂/N₁. Step-up voltage badhata hai; step-down voltage ghataata hai.
🧩 Examples
N₂>N₁ ⇒ secondary voltage higher.
💡 Exam Tip

Power transmission aur distribution mein widely used.

📌 Definition

Motors electrical energy ko mechanical energy mein aur generators mechanical energy ko electrical energy mein convert karte hain.

📚 Key Formula / Points
Motor principle: force on current-carrying conductor in magnetic field. Generator: electromagnetic induction.
🧩 Examples
Fan motor electrical input ko rotation mein convert karta hai.
💡 Exam Tip

Industry, transport aur household appliances mein common.

Programming for Problem Solving (C)

8 detailed topics • Definition • Key points • Examples

📌 Definition

C ek procedural, compiled programming language hai.

📚 Key Formula / Points
Typical structure: #include <stdio.h> int main(){ ... return 0; }
🧩 Examples
printf("Hello"); screen par Hello print karta hai.
💡 Exam Tip

Clean structure debugging aur readability improve karta hai.

📌 Definition

Variable memory location ka named identifier hai jisme value store hoti hai.

📚 Key Formula / Points
Common types: int, char, float, double. Declaration: int age=19;
🧩 Examples
int a=10,b=20; int sum=a+b;
💡 Exam Tip

Correct data type memory aur calculation accuracy ke liye important.

📌 Definition

Operators values par operations perform karte hain.

📚 Key Formula / Points
Arithmetic: + - * / % Relational: < > == != Logical: && || ! Assignment: = Increment: ++
🧩 Examples
if(a%2==0) even check hota hai.
💡 Exam Tip

Operator precedence ko expressions mein dhyan se use karo.

📌 Definition

Condition ke basis par different code execute karne ke liye if, if-else aur switch use hote hain.

📚 Key Formula / Points
if(condition){ ... } else{ ... } switch fixed choices ke liye useful hai.
🧩 Examples
marks>=40 ? Pass : Fail;
💡 Exam Tip

Decision-making programs ka base.

📌 Definition

Repeated execution ke liye loops use hote hain.

📚 Key Formula / Points
for loop known repetitions ke liye. while condition-based repetition ke liye. do-while at least once execute hota hai.
🧩 Examples
for(i=1;i<=5;i++) printf("%d ",i);
💡 Exam Tip

Infinite loop se bachne ke liye update condition check karo.

📌 Definition

Same data type ki multiple values ko contiguous indexed collection mein store karne ke liye array use hota hai.

📚 Key Formula / Points
int a[5]; indices 0 se 4. 2D array matrix-like data ke liye.
🧩 Examples
Sum of array elements using for loop.
💡 Exam Tip

Searching, sorting aur tabular data mein useful.

📌 Definition

Reusable block of code jo specific task perform karta hai function kehlata hai.

📚 Key Formula / Points
Parts: declaration/prototype, definition, call. Parameters aur return value ho sakti hai.
🧩 Examples
int add(int a,int b){ return a+b; }
💡 Exam Tip

Modular programming aur code reuse improve hota hai.

📌 Definition

Pointer ek variable ka memory address store karta hai.

📚 Key Formula / Points
int *p=&x; *p se x ki value access hoti hai.
🧩 Examples
Swap function mein addresses pass karke original values change kar sakte hain.
💡 Exam Tip

Dynamic memory, arrays aur low-level programming mein important.

Soft Skills & Communication

8 detailed topics • Definition • Key points • Examples

📌 Definition

Ideas, information ya feelings ko sender se receiver tak effectively convey karna communication hai.

📚 Key Formula / Points
Sender, message, channel, receiver aur feedback basic elements hain.
🧩 Examples
Teacher ka concept explain karna + student ka question/feedback complete communication cycle hai.
💡 Exam Tip

Clear language aur active listening communication improve karte hain.

📌 Definition

Words ke through verbal communication aur gestures, facial expressions, posture, eye contact etc. non-verbal communication hain.

📚 Key Formula / Points
Tone, pace aur body language message ke impact ko change kar sakte hain.
🧩 Examples
Interview mein confident posture aur clear answer positive impression create karte hain.
💡 Exam Tip

Professional life mein dono ko balance karna zaroori.

📌 Definition

Speaker ko attention se sunna, understand karna aur relevant response dena active listening hai.

📚 Key Formula / Points
Eye contact, clarification questions, paraphrasing aur interruptions avoid karna useful habits hain.
🧩 Examples
Group discussion mein pehle dusre member ki point ko summarize karke apna point add karna.
💡 Exam Tip

Misunderstanding reduce hoti hai.

📌 Definition

Information ko structured, clear aur engaging way mein audience ke saamne present karna presentation skill hai.

📚 Key Formula / Points
Structure: opening → main points → examples/data → conclusion. Slides simple rakho.
🧩 Examples
Problem + why it matters + what you will cover.
💡 Exam Tip

Confidence, voice modulation aur time management important.

📌 Definition

GD mein group ke members ek topic par ideas share aur evaluate karte hain.

📚 Key Formula / Points
Good GD participant relevant points, respectful disagreement, listening aur evidence-based reasoning dikhata hai.
🧩 Examples
AI in education par advantages + limitations + practical solution discuss karna.
💡 Exam Tip

Sirf bolna nahi; listening aur collaboration bhi assess hote hain.

📌 Definition

Interview mein knowledge, communication, confidence, attitude aur problem-solving ko evaluate kiya ja sakta hai.

📚 Key Formula / Points
STAR method: Situation, Task, Action, Result.
🧩 Examples
Project failure explain karte waqt problem, action aur measurable result batao.
💡 Exam Tip

Honest answers aur preparation strongest strategy hai.

📌 Definition

Resume ek concise professional document hai jo education, skills, projects aur achievements ko highlight karta hai.

📚 Key Formula / Points
Sections: contact, summary/objective, education, skills, projects, achievements, certifications.
🧩 Examples
Built a responsive study website with HTML/CSS/JS and search feature.
💡 Exam Tip

Truthful, readable aur role-focused resume best hota hai.

📌 Definition

Limited time ko priorities ke according plan karke productive use karna time management hai.

📚 Key Formula / Points
To-do list, priority matrix, Pomodoro blocks aur daily review useful techniques hain.
🧩 Examples
50 min Maths + 10 min break, then 50 min C practice.
💡 Exam Tip

Consistency motivation se zyada important hoti hai.
